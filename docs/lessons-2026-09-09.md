# 2026-09-09 のセッションで分かったこと

バッチ版(C:\Users\takay\navkit)を作る過程で踏んだ問題。Rust 版の設計根拠。

| 事象 | 原因 | Rust 版での扱い |
|---|---|---|
| cmd で `c` に渡した `^` が消える | `call` と `for /f` の子 cmd が二重に `^` を処理 | クエリは環境変数で渡す |
| `for /f ('"C:\...\fd.exe" ... ^| "C:\...\fzf.exe"')` が壊れる | cmd /c の引用符剥がし規則 | 本体を 1 exe にし、for /f の中でパスを引用しない |
| `endlocal & cd "!P!"` が動かない | `&` 連結の各コマンド直前に遅延展開されるため endlocal 後は空 | シムは for 変数に受けてから endlocal(定石) |
| PowerShell で `function z` が呼ばれない | zoxide init の alias が優先 | シム出力で Remove-Alias を先に出す |
| pwsh の `param($Args)` で引数が空 | 自動変数 `$args` と衝突 | 使わない |
| fd の出力末尾 `\` が引数を壊す | MSVC 引数解析の `\"` | 出力パスに末尾区切りを付けない |
| PowerShell から cmd へ `-Command "..."` で引用符が消える | pwsh の Windows 引数渡し + cmd の解釈 | テストは .ps1 ファイル経由で行う |
| 走査速度 | `dir /s /b` 0.5〜1.0 s、fd 0.1 s(14 万ファイル) | ignore クレートで fd 同等 |
| WezTerm の分割ペインがホームで開く | シェルが OSC 7 を出していなかった | (参考)プロファイルで出すようにした |
| WezTerm の Lua `pane:split` が cwd を無視 | `file_path` が `/C:/...` 形式で返る | (参考)先頭の `/` を落として渡す |
